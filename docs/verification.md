## 当前调查与下一步

Apple 的 macOS 27 发布说明确认了系统原生菜单栏溢出。当前看到的 MenuBarAgent“隐藏菜单栏项目”按钮可能对应这个原生展示状态；仅依据按钮名称无法确定。已执行一次收起尝试，之后 Mac 锁定使观察中断，因此没有得出结论。下一步应先可逆验证系统展开/收起、图标独立坐标与命中，再单独验证边界空间分配，最后验收指定图标的隐藏和原生交互。

不在占位坐标注入拖动，不将事件发送成功当成移动成功，不将受控边界检查当成真实系统兼容性。相关 API 依据见 [研究报告](research/apple-menu-bar-api-audit.md)。
