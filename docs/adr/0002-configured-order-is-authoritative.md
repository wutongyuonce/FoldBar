# 配置顺序独立于实时菜单栏排列

用户于 2026-10-18 确认：首次出现的图标加入显示组末尾并立即登记，同时发现的多个新图标按检测时菜单栏从左到右的顺序登记。此后应用退出、重启或重新出现均保留相对顺序，只有用户主动调整才改变已登记图标之间的顺序。

设置页分为显示组和隐藏组，组内从左到右排列，跨组拖动改变显隐。实时枚举结果只是当前运行情况，不能覆盖已保存顺序；缺席图标继续保留登记。身份不明确时显式提示，不能将另一图标的配置错误应用到当前图标。

配置顺序和显隐是全局的，同步应用于本机所有桌面（Spaces）和连接的显示器。切换桌面、连接或拔掉显示器后自动恢复这同一份布局，不提供每个桌面或显示器单独配置；这些场景属于 1.0 的必要验收范围。

用户进一步确认：自动隐藏菜单栏和全屏应用也是必要场景。系统菜单栏被唤出后，FoldBar 箭头与下拉栏应正常使用；不能将这两种场景默认为不支持。
