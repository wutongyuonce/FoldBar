# Triage Labels

| Canonical role | Local status | Meaning |
| --- | --- | --- |
| needs-triage | needs-triage | Needs evaluation |
| needs-info | needs-info | Needs clarification |
| ready-for-agent | ready-for-agent | Specified and ready for agent work |
| ready-for-human | ready-for-human | Requires human implementation |
| wontfix | wontfix | Will not be implemented |

Use these values in ticket Status fields; no GitHub labels are created.
